📱 悦读绘本 · 原生 iOS/Android 实现方案

面向「孩子自主使用」的英语绘本跟读 App ｜ MVP 范围、技术栈、API 接入、数据模型与路线图
交付定位：本方案说明如何把浏览器原型落为真正的原生 App（SwiftUI + Kotlin/Jetpack Compose），核心难点「跟读评分纠错」「拍照 OCR 录入」均按你选择的成熟 API方案设计，密钥放后端代理、不落端。

1. MVP 范围（第一版只做这些）

绘本库浏览分级筛选领读 TTS 跟读录音发音评分+纠错拍照 OCR 录入 成长记录薄弱点分析打卡/徽章

暂不做（V2）：AI 真人纠音视频、社区/UGC、直播课、付费会员体系、多_child 账号切换。

4. 核心能力接入（关键代码示意）

4.1 跟读评分（腾讯云 语音评测 Soe / 讯飞 语音评测）

流程：录音(WAV) → 后端上传音频+原文 → 评测服务返回整体分 + 每个单词的准确度 → 端上高亮纠错。

// 后端(Node)伪代码：转发到腾讯云/讯飞，避免密钥暴露
app.post('/api/score', upload.single('audio'), async (req,res)=>{
  const { text } = req.body;
  const audio = req.file.buffer;            // 16k 单声道 wav
  const r = await soe.evaluate({ text, audio,
      precision: 'phoneme' });              // 音素级，可定位到字母
  res.json({ score: r.overall,
             words: r.words.map(w=>({w:w.word, score:w.accuracy})),
             fixes: r.words.filter(w=>w.accuracy<75).map(...) });
});
厂商优势注意
腾讯云 语音评测中文厂商、儿童音适配好、按次计费低需企业实名
讯飞 语音评测教育场景成熟、纠音维度全额度/商务门槛
Azure Pronunciation Assessment英文 native 评分准、全球可用英文为主、需境外网络
推荐：英文跟读优先 Azure Pronunciation Assessment 或 讯飞英文评测；中文混读再补腾讯云。MVP 先接一家跑通。

4.2 拍照 OCR 录入

// Android(ML Kit 端侧，免费无需联网) 示例
val recognizer = TextRecognition.getClient(TextRecognizerOptions.DEFAULT_OPTIONS)
recognizer.process(image)
  .addOnSuccessListener { visionText ->
      val lines = visionText.text.lines()
      buildBookFromOcr(lines)   // 自动切句、建绘本条目
  }

也可走云端 OCR（腾讯云/百度）做版面分析，更准但按张计费。端侧 ML Kit 适合 MVP 控制成本。

4.3 领读 TTS（端侧免费）

iOS 用 AVSpeechSynthesizer、Android 用 TextToSpeech，选 en-US 女声、语速 0.8x 更适合跟读。无需任何 API。

7. 资源合规（重要）

版权红线：牛津阅读树、红火箭、神奇校车均受版权保护，不可直接抓取/分发正文与图。正式上线须：
  • 采购正版授权 / 与出版社合作；或
  • 仅接入 公版(Public Domain) 资源（如 Project Gutenberg 儿童公版读物、部分超过版权期的绘本）；或
  • 用户自己拍照录入的私有绘本（你已规划此功能，合规且差异化）。
原型中的示例仅用于演示交互，不内含受版权内容。

9. 成本与风险

预估月成本（千活跃用户量级）：语音评测 ~¥0.01–0.03/次、OCR ~¥0.005/张、存储与流量几百元/月；端侧 TTS 免费。前期可用免费额度验证。

主要风险：① 儿童发音评测准确率（需调阈值/多读几次取最优）；② 绘本版权；③ 真机麦克风权限与后台评测延迟。

下一步建议：先用今天这份 浏览器原型 验证孩子使用流程与交互，确认后再按本方案启动原生工程；语音评测建议先申请 一家 厂商试用密钥做技术验证。
